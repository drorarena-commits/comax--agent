# איך נבנה reel-hot-shelf-2026-09-13.mp4

מונטאז' תמונות, לא צילום — נבנה מקומית לגמרי, בלי קנבה, כי חסר לי גם מצלמה
לצילום אמיתי וגם דרך להעלות את תמונות המוצר המקומיות לקנבה בלי URL ציבורי.

**התהליך:**
1. `build-frames.mjs` — Playwright פותח כל שקף כ-HTML (1080×1920, זהה לסגנון
   `carousel-top-stock`) ומצלם PNG. תמונות המוצר כבר קיימות ב-
   `runs/carousel-top-stock/img/` מבניית הקרוסלה.
2. `ffmpeg-static` (נוסף כ-devDependency) מרכיב את 8 ה-PNG לכדי MP4 עם משך
   זמן לכל שקף לפי `concat.txt`, תואם לתזמון בתסריט `reel-concept-2026-09-13.md`.

⚠️ **מלכודת שתפסה כאן**: `page.setContent()` נותן למסמך מקור `about:blank`,
וכרום חוסם טעינת `file://` ממקור כזה מטעמי אבטחה — התמונות נכשלות בשקט עם
סמל שבור. הפתרון: לכתוב HTML לקובץ זמני ולנווט אליו עם
`page.goto(pathToFileURL(...))`, בדיוק כמו ש-`carousel-top-stock/build.mjs`
כבר עשה נכון.
