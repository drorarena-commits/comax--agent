  ולקרוא שורות. הפרופיל מצהיר `hasItemFilter: false`.

  קריאת רשת לפי תווית נשברת על התו הזה.

  התאמה על "Doc650" בלבד תופסת גם אותו — לגזור את הקידומת מה-URL.

## שלושת השערים לפני הקליטה

`finalize` קורא הכל מחדש מהמסך רגע לפני הלחיצה, ומסרב ב-`--confirm` בדיוק כמו
בלעדיו — שער שעובד רק ב-dry-run אינו שער.

1. **הסכום חייב להיקרא.** חשבונית שאי אפשר לקרוא את הסכום שלה היא חשבונית שאף
   אחד לא אימת.
2. **משטר המע"מ חייב להיות ידוע**, לא מונח. שני עדים בלתי תלויים:
   - **מה שקומקס מצהיר** — הפוטר כותב `לפי מחירון: מכירה ראשי (כולל מע''מ)`.
     בלי סיומת = לפני מע"מ. זה העד הטוב יותר, כי הוא נכון גם למחירון שאיש לא
     רשם. (הגרשיים הם שני אפוסטרופים — `priceListFrom()` מקבל כל וריאנט.)
   - **מה שהמספרים אומרים** — `vatRegime()` בודק על מי מ-`ScmBeforeMaam`
     ו-`Scm` נופל סכום השורות.
3. **שני העדים לא יסתרו זה את זה.** סתירה = סירוב.

עד אחד לבדו מתקבל ומסומן במקור שלו. שתיקה משניהם = סירוב. **אף פעם לא ברירת
מחדל** — זה בדיוק הכשל שעלה 15% תת-גבייה ב-6120045, שם `wholesale: true` כתב
מחיר נטו למחירון כולל מע"מ והמסמך נראה תקין לגמרי.

בנוסף: סה"כ מסמך **נמוך** מסכום השורות נרשם כאזהרה בלוג (הנחת מסמך?) — לא חוסם,
אבל נראה לפני שהמלאי זז ולא אחרי.

הלוגיקה ב-[index.js](index.js) (`resolveVatRegime`), על `readTotals` ו-`vatRegime`
מ-[src/document-totals.js](../../../document-totals.js) — אותו קוד ש-
`customer-history` קורא בו מסמכים קיימים. אם צד הכתיבה וצד הקריאה יסכימו על
המשטר, אחד מהם טועה בשיעור המע"מ המלא.

## איך למפות את מה שחסר

```bash
npm run open-program -- a157
# ואז, אחרי לחיצה על #newRec:
npm run snapshot -- invoice-header
# ואחרי אישור הכותרת:
npm run snapshot -- invoice-lines
```

⚠️ **לחיצה על `#newRec` יוצרת טיוטת חשבונית אמיתית.** `MAP.md` מתעד שטיוטה
שלא הופקה נתפסת מחדש בהרצה הבאה על אותו לקוח. לכן: למפות דרך מסמך אמיתי
שממילא רוצים ליצור, ב-`dryRun`, ולצאת ב-`backOut` (`#DoExit` → `#Cancel`)
אם מחליטים לא לקלוט.

אחרי המיפוי — לעדכן `mapped` ב-[index.js](index.js) ולוודא שה-id תואמים.
`Doc612` משתמש ב-`#IdxLk`, `#Store`, `#Mhr`, `#DateDoc`, `#Sochen`, `#Pratim`
לכותרת, ו-`#Prt`, `#Cmt`, `#Mhr`, `#AczDis`, `#Scm` לשורה. **כל ה-id האלה
בפרופיל הם כרגע העתקה מ-Doc612 ולא נראו על Doc650 מעולם** — `mapped:false`
חוסם ריצה עליהם, אבל אל תתייחס אליהם כידועים. לאמת, לא להניח.
