# סוכן־העל — `registry.js`

המנצח על סוכני המסמכים. מנתב, בודק מוכנות, ומשרשר.

## מה הוא עושה — ושלושת הדברים האלה בלבד

1. **ניתוב** — `get('חשבונית מס')` מחזיר את הסוכן הנכון. שם לא מוכר מקבל סירוב
   עם רשימת הקיימים, לא ניחוש של הדומה ביותר.
2. **מוכנות** — `assertReady(agent)` עוצר **לפני הקליק הראשון** אם מסך שהזרימה
   צריכה לא מופה. זה מכוון: לגלות שמסך השורות לא ידוע *אחרי* שהכותרת נקלטה
   משאיר מסמך אמיתי פתוח בקומקס בלי שורות.
3. **שרשור** — `chain(ctx, steps)` מריץ מסמך אחרי מסמך ונעצר בכישלון הראשון,
   אחרי `backOut` על המסמך שנכשל. המוכנות של **כל** השלבים נבדקת לפני שהראשון
   מתחיל, כדי שחשבונית לא תיקלט ואז תעודת ההעברה שאמורה לאזן אותה לא תקרה.

## מה הוא בכוונה לא עושה

הוא לא יודע איך שום מסמך מתנהג. הידע הזה שייך לסוכן — חשבונית מזיזה מלאי ברגע
הקליטה, הצעה אפשר לנטוש, לתעודת העברה אין לקוח בכלל, ולקבלה אין פריטים —
ומשיכה שלו לכאן הופכת חמישה מומחים לגנרליסט בינוני אחד.

## API

```js
import * as registry from './src/documents/registry.js';

registry.list()                    // כל הסוכנים + מצב המיפוי שלהם
registry.get('חשבונית מס')          // הסוכן, לפי שם או תווית עברית
registry.assertReady(agent)        // זורק אם משהו לא מופה
await registry.chain(ctx, [
  { document: 'חשבונית מס', input: {...}, items: [...], confirm: true },
  { document: 'העברה',      input: {...}, items: [...], confirm: true },
])
```

## להוסיף סוכן חדש

1. `src/documents/agents/<שם>/index.js` — `export const profile` + `create`,
   `addLines`, `finalize`, `backOut`.
2. `src/documents/agents/<שם>/AGENT.md` — מה מיוחד במסמך הזה.
3. לרשום ב-`AGENTS` וב-`ALIASES` ב-[registry.js](registry.js).

`profile.mapped` הוא הבלם: `{ list, header, lines }`. מה שלא הוכח בהרצה חיה
נשאר `false`.

## כלל הבטיחות שלא מתרככים בו

במסך **שורות** ‏`#OK` מתויג "(Alt+e) קליטת חשבונית" והוא **קולט את המסמך**.
במסך **כותרת** אותו `#OK` רק מתקדם לשורות. לכן `commitHeader` מסרב ללחוץ אם
ה-frame שאליו הוא מכוון אינו כותרת, ו-`finalize` היא הפונקציה היחידה שמותר
לה ללחוץ על `#OK` של מסך שורות. היציאה בלי קליטה היא `#DoExit` ואז `#Cancel`.
