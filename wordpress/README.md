# תוספי וורדפרס של אתר ארנה ישראל

קוד PHP שרץ **בתוך** `arenaisrael.co.il`, להבדיל מכל השאר בריפו שרץ על המחשב.
אי אפשר להתקין אותו דרך ה-API — לא WooCommerce REST ולא ה-MCP של וורדפרס
("Cannot install new plugin code") — ולכן כל קובץ כאן מגיע בשתי צורות: תוסף
להעלאה, וגרסת הדבקה ל-Code Snippets.

⚠️ **אבל "ה-API מסרב" אינו "צריך שדרור יעשה ידנית".** ב-15/09/2026 נמסרו לדרור
הוראות התקנה ידניות בנימוק הזה, והוא שאל למה הסוכן לא נכנס לכרום ומדביק בעצמו.
הוא צדק: Code Snippets הוא מסך רגיל בוורדפרס, והכרום מחובר לסוכן. **ההתקנה
בוצעה מקצה לקצה על ידי הסוכן** — ראה "התקנה על ידי הסוכן" למטה.

⚠️ **אין PHP מותקן על מחשב הסוכן.** `php -l` לא זמין, ושגיאת תחביר בתוסף
וורדפרס מפילה את האדמין כולו. לכן כל קובץ כאן נבדק לפני מסירה עם
`php-parser` (npm, `--no-save`) על ה-PHP ו-`node --check` על ה-JS שמוטמע בו.
זו הסיבה שהקוד כתוב בלי `const` ברמת קובץ ובלי `?>` באמצע — שניהם נשברים
בתוך ה-`eval` של Code Snippets, ו-nowdoc עובד בשתי דרכי ההתקנה.

## `arena-order-item-thumb` — תמונת הווריאציה במסך ההזמנה

**הבעיה שדרור דיווח עליה (15/09/2026):** במסך עריכת ההזמנה בווקומרס, התמונה
שליד כל פריט היא **התמונה הכללית של המוצר** ולא הצבע שהלקוח באמת הזמין, וגם
אי אפשר ללחוץ עליה כדי להגדיל. מי שמלקט את ההזמנה מחפש לפי התמונה — וממילא
מחפש את הצבע הלא נכון.

**השורש:** באתר פעיל התוסף `arena-parent-display_v1.1.0`
("Arena - הצגת מוצר אב (הזמנות + וריאציות)"), שמחליף את הפריט בשורת ההזמנה
במוצר האב. התמונה היא תוצר לוואי שלו, לא תקלה של ווקומרס.

**התיקון** נתלה על `woocommerce_admin_order_item_thumbnail` ב-priority 9999 —
כלומר **אחרי** התוסף הקיים, ובלי לבטל אותו: שאר ההתנהגות שלו (שם המוצר,
הקישור לאב) נשארת, ורק התמונה חוזרת לווריאציה.

### שלוש מלכודות שהקוד עוקף

1. **`WC_Product_Variation::get_image()` נופל בשקט לתמונת האב** כשלווריאציה
   אין תמונה משלה, ולכן "חזרה תמונה" אינו אומר שהיא של הצבע הנכון. הבדיקה
   האמיתית היא `get_post_thumbnail_id( $variation_id )`. נמדד מול ה-REST:
   ווריאציה 74648 החזירה בדיוק את קובץ האב. כשזה קורה התמונה מסומנת במסגרת
   כתומה מקווקוות — כדי שהמלקט ידע שהוא לא רואה את הצבע.
2. **`wp_kses_post` מסנן תכונות `data-*`.** הטמפלייט של ווקומרס מעביר את
   הפלט דרכו, ולכן כתובת התמונה המוגדלת יושבת ב-`href` ולא ב-`data-`.
3. **טבלת הפריטים נטענת מחדש ב-AJAX** אחרי כל עריכת הזמנה. מאזין שנקשר
   לתמונה עצמה מת שם בלי שגיאה, ולכן ההאזנה היא delegation על `document`.

### התקנה

**הדרך המומלצת — Code Snippets** (מותקן ופעיל באתר). הוא בודק את התחביר
לפני שמירה ומשבית snippet שגורם ל-fatal, ולכן הוא הדרך הבטוחה מהשתיים:

1. וורדפרס → **קטעי קוד (Snippets)** → **הוסף חדש**
2. כותרת: `Arena — תמונת הווריאציה במסך ההזמנה`
3. להדביק את כל תוכן [`arena-order-item-thumb/code-snippet.txt`](arena-order-item-thumb/code-snippet.txt)
   — **בלי** `<?php` בתחילתו
4. לסמן **"הרץ בפאנל הניהול בלבד"** (Only run in administration area)
5. שמירה והפעלה

**החלופה — התקנה כתוסף:** תוספים → הוסף חדש → העלאת תוסף →
[`arena-order-item-thumb.zip`](arena-order-item-thumb.zip).

### התקנה על ידי הסוכן (דרך הדפדפן)

**מצב נוכחי:** מותקן ופעיל באתר כ-snippet **מספר 56** (עודכן 15/09 לכיתוב שלוש השורות), בהיקף
`Only run in administration area`, עדיפות 10. הותקן על ידי הסוכן ב-15/09/2026
ואומת על הזמנה 79049 (AIR-BOLD SWIPE, צבע SMOKE-SMOKE-BLACK-102).

הסוכן מנווט ל-`admin.php?page=add-snippet`, ממלא כותרת, ומדביק את הקוד. שלוש
נקודות שנלמדו בהרצה:

1. **להעביר את הקוד דרך הלוח, לא בהקלדה.** הקלדה תו-תו לתוך CodeMirror איטית
   ומייצרת שגיאות תחביר, ושגיאת PHP מפילה את האדמין. `Set-Clipboard` קורא את
   הקובץ ישירות (`[System.IO.File]::ReadAllText` ב-UTF-8), ואז קליק בעורך,
   `ctrl+a`, `ctrl+v` — כך התוכן **אינו עובר דרך המודל** ואף תו לא נשבר.
2. **לאמת באורך התווים, לא במראה.** `cm.getValue().length` מול אורך הקובץ —
   נמדד 6,743 בשני הצדדים. הדבקה חלקית נראית כמו קוד תקין על המסך.
3. **שדה הסיסמה שכרום מילא אוטומטית מחזיר מחרוזת ריקה ל-JavaScript** עד
   אינטראקציה אמיתית של המשתמש. זו התנהגות אבטחה, לא שדה ריק — פשוט ללחוץ
   "התחבר".

### בדיקה שזה עבד

לפתוח הזמנה עם פריט צבעוני ולוודא שלושה דברים: התמונה היא של הצבע שהוזמן,
לחיצה עליה פותחת הגדלה עם שם הפריט והצבע מתחתיה, ו-Esc או לחיצה על הרקע
סוגרים. **הגדלה שנפתחת עם תמונה של צבע אחר היא כישלון שנראה כמו הצלחה** —
ההשוואה היא מול שם הצבע שבשורת ההזמנה עצמה.

### הכיתוב שמתחת להגדלה — שלוש שורות

מי שמלקט מחזיק את הפריט ביד ומשווה, ולכן הכיתוב אינו שם הפריט הארוך אלא
שלושת המזהים שמודפסים על המדבקה, באותו סדר שבו הוא קורא אותם:

1. `004714-102-SMOKE-SMOKE-BLACK-One size` — דגם-צבע-מידה, גדול ומודגש.
2. `AIR-BOLD SWIPE משקפת` — שם המוצר במילים.
3. `3468336643099` — הברקוד, בגופן רחב ומרווח לקריאה ספרה-ספרה.

הדגם מגיע מ-`_parent_sku` של הווריאציה (מספר הדגם בקומקס), ולא מ-ID של
וורדפרס. הצבע והמידה הם **שמות המונחים** ולא ה-slug.

⚠️ **הכיתוב אינו זהה לזה שבאפליקציית ההזמנות, וזה מכוון.** באתר הצבע הוא
`102-SMOKE-SMOKE-BLACK` והמידה `One size`; באותו פריט בקומקס הצבע הוא
`102` והמידה `Os`, ולכן האפליקציה מציגה `004714-102-Os`. נרמול בין
השניים היה ניחוש שעלול להצמיד כיתוב לפריט אחר — ולכן הערכים נלקחים כפי
שהם בכל מערכת, **והברקוד, שזהה בשתיהן, הוא עוגן האימות.**

הכיתוב עובר ב-`title` כשורות מופרדות בשורה חדשה, כי `wp_kses_post` מסנן
`data-*`. ה-JS מפצל אותן ונותן לכל שורה מחלקה משלה.

### כוונון

התמונה בשורה מוגדלת מ-38px (ברירת המחדל של ווקומרס) ל-48px, כדי שהצבע יהיה
קריא בלי לחיצה. זה שני מופעים של `48px` בבלוק ה-CSS, וניתן לשנות או למחוק.
