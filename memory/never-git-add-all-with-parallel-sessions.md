בפרויקט COMAX AGENT רצים לעיתים **שני סשנים במקביל על אותה תיקיית עבודה** —
למשל סשן עבודה שדרור פתח, לצד הסשן האוטומטי של הייצוא הלילי. במצב הזה
**`git add -A` אינו בטוח**: הוא סוחף לתוך הקומיט שלי גם קבצים שהסשן השני
כתב וטרם קימט.

## מה שקרה בפועל

ב-15/09/2026 קימטתי snippet חדש עם `git add -A`, והקומיט בלע גם 389 שורות
שסשן הייצוא הלילי כתב באותו רגע — `src/download.js` (קובץ חדש), `src/browser.js`,
`src/tasks/items-export.js` ו-`src/tasks/stock-export.js`. הקוד עצמו תקין ולא
נפגע, אבל ההיסטוריה יצאה מטעה: קומיט שכותרתו "שער קריאת תמונות ווריאציה"
מכיל בתוכו תיקון להורדת קבצים מקומקס.

דרור ביקש **קומיט מתקן שמסביר**, ולא שכתוב היסטוריה — הקומיט כבר נדחף,
והתיקון הנכון הוא הבהרה נוספת ולא `rebase` או `force`.

## הכלל

1. **לקמט לפי נתיבים מפורשים** — `git add <קובץ> <קובץ>` ולא `-A`, כשידוע
   שיש סשן נוסף פעיל.
2. **לקרוא `git status` לפני ההוספה** ולוודא שכל קובץ ברשימה הוא באמת שלי.
   קובץ מוכר שלא נגעתי בו הוא סימן לעבודה מקבילה.
3. **אם זה כבר קרה ונדחף** — להתריע לדרור מיד ולהציע קומיט מתקן שמסביר מה
   נכנס ולמה. לא לגעת בהיסטוריה שנדחפה בלי אישור מפורש.
