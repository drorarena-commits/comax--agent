אחרי סבב עבודה ארוך שבו נוצרו מודולים חדשים, שתי משימות, ותיעוד נרחב, דרור
שאל: **"אתה מגבה הכל לגיט ולגיטהאב?"** — ולא הייתי. עבדתי שעות בלי קומיט אחד.

`CLAUDE.md` מגדיר `push-comax` כפקודה שלו ל-`git add . && git commit && git push`,
ופירשתי את זה כאילו גיבוי קורה **רק** כשהוא אומר את המילה. השאלה שלו מלמדת
שהציפייה רחבה יותר: הפרויקט עובד משני מחשבים ומסונכרן דרך GitHub, ועבודה
שיושבת רק על דיסק אחד היא עבודה בסיכון.

**מה לעשות בפועל:** לגבות בנקודות עצירה טבעיות — יכולת חדשה שהושלמה ואומתה,
ממצא שתועד, או לפני התחלת שלב גדול חדש — ולומר לו שגיביתי ומה נכנס. לא צריך
לחכות למילת הקסם, וגם לא לגבות אחרי כל עריכה קטנה.

⚠️ שים לב שזו הרחבה של הרגלי העבודה **בפרויקט הזה בלבד**, שבו הגיבוי הוא חלק
מהתשתית ולא החלטה של המפתח. ברירת המחדל הכללית — לא לקמט ולא לדחוף בלי בקשה —
נשארת במקומה בכל מקום אחר.
