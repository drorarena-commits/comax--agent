# הקמת מוצרים באתר ארנה ישראל — המבנה, השערים והמלכודות

עדכון אחרון: **12/09/2026**. נמדד חי מול `arenaisrael.co.il` דרך ה-MCP של
וורדפרס (קריאה בלבד) — 401 מוצרים מפורסמים, WooCommerce על תבנית **Flatsome**.

**הסוכן שמחזיק את זה: [`arena-item-setup`](../.claude/agents/arena-item-setup.md).**
המסמך הזה הוא הידע; הסוכן הוא מי שקורא אותו לפני שהוא כותב לאתר.

⚠️ **מצב: המבנה מופו ואומת בקריאה · היצירה עצמה עדיין לא הורצה.** אין להקים
מוצר ראשון בלי שדרור צופה בהרצה. ראו "מה עדיין לא אומת" בסוף.

## היחידה שמקימים

מוצר ארנה טיפוסי באתר הוא **מוצר משתנה (variable)**:

```
product (הורה)            ← דגם.  _sku = קוד הדגם (למשל 004766)
└── product_variation     ← צבע × מידה.  _sku = הברקוד (EAN, 13 ספרות)
```

**זה המקום שבו הכי קל לטעות:** ה-`_sku` של ההורה **אינו ברקוד** אלא קוד הדגם,
וה-`_sku` של הווריאציה **הוא** הברקוד. רק הווריאציה היא זו שהתוסף מצליב מול
קומקס, ולכן רק היא חייבת להיות זהה בדיוק למק"ט בקומקס
(`site-comax-sku-must-match`).

## מפת השדות — נמדדה על מוצרים חיים

### ההורה (`post_type: product`)

| שדה | ערך | מקור/דוגמה |
|---|---|---|
| `title` | שם עברי + שם הדגם באנגלית | `בגד ים שלם לנשים WOMEN'S TEAM SWIMSUIT CHALLENGE SOLID` |
| `terms.product_type` | `variable` (או `simple` לפריט בלי צבע/מידה) | |
| `terms.product_cat` | קטגוריות — **תמיד גם קטגוריית קהל** (נשים/גברים/ילדים ונוער/יוניסקס) **וגם קטגוריית מוצר** | `["בגדי ים","בגדי ים שלמים","נשים"]` |
| `terms.pa_color` | כל הצבעים של הדגם | `803-NEON BLUE-TEAM ORANGE` |
| `terms.pa_size` | כל המידות | `32,34,36,38,40,42` |
| `meta._sku` · `meta._parent_sku` | **קוד הדגם**, זהה בשניהם | `004766` |
| `meta._product_attributes` | ראו למטה — **חובה, אחרת אין ווריאציות** | |
| `meta._default_attributes` | הצבע והמידה שנפתחים כברירת מחדל, **בסלאגים** | `{"pa_color":"803-neon-blue-team-orange","pa_size":"32"}` |
| `meta._price` | המחיר שמוצג בארכיון | `199` |
| `meta._manage_stock` | `no` בהורה — המלאי יושב בווריאציות | |
| `meta._thumbnail_id` · `_product_image_gallery` | תמונה ראשית + גלריה (מזהי מדיה, פסיקים) | `77117` · `78216,78213,78215` |
| `meta.additional_description` | **הרכב הבד/החומר** — שדה ACF שמוצג בכרטיס | `הרכב בד: 100% פוליאסטר` |
| `meta._additional_description` | `field_638896180e1c6` — **מפתח ה-ACF, חייב להיכתב יחד איתו** | |
| `excerpt` | התיאור הקצר — שתי פסקאות HTML | |

**`_product_attributes`** — המבנה המדויק שנמדד, ובלעדיו WooCommerce לא יידע
שהמוצר משתנה:

```json
{"pa_color":{"name":"pa_color","value":"","position":0,"is_visible":1,"is_variation":1,"is_taxonomy":1},
 "pa_size": {"name":"pa_size", "value":"","position":1,"is_visible":1,"is_variation":1,"is_taxonomy":1}}
```

### הווריאציה (`post_type: product_variation`, `parent` = מזהה ההורה)

| שדה | ערך |
|---|---|
| `meta.attribute_pa_color` · `attribute_pa_size` | **הסלאג של המונח**, לא שמו — `906-very-fuchsia-team-green` · `36` |
| `meta._sku` | **הברקוד. זה המפתח לקומקס** — `3468337730286` |
| `meta._regular_price` **וגם** `meta._price` | שניהם. `_price` לבדו לא נשמר, `_regular_price` לבדו לא מוצג |
| `meta._manage_stock` = `yes` · `_stock` · `_stock_status` | המלאי הראשוני; מכאן והלאה הסנכרון מקומקס מעדכן |
| `meta._tax_class` | `parent` |
| `meta._thumbnail_id` | **תמונת הצבע** |
| `meta._ux_additional_variation_images` | **שאר תמונות הצבע**, מזהי מדיה מופרדים בפסיקים |

## התמונות — הכלל שמחבר את הסקיל לאתר

**התמונות באתר הן ברמת הצבע, לא ברמת המידה.** כל הווריאציות של אותו צבע
נושאות **בדיוק את אותם** `_thumbnail_id` ו-`_ux_additional_variation_images`.
נמדד על 004766: שש מידות בצבע 906, כולן `_thumbnail_id: 77113` ו-
`_ux_additional_variation_images: 77114,77115,77116`.

זה בדיוק מה שהסקיל **`arena-image-sourcing`** מייצר: 4 תמונות לכל
מק"ט-צבע. אחת נעשית `_thumbnail_id` והשאר `_ux_additional_variation_images`,
ואותה רביעייה נכתבת לכל המידות של הצבע.

`_ux_additional_variation_images` הוא תוסף של Flatsome. **שם השדה הזה אינו
מנחש — הוא נמדד**, ואסור להחליף אותו ב-`_product_image_gallery` ברמת הווריאציה.

## שלושת השערים שלפני הכתיבה

1. **הפריט קיים בקומקס, עם אותו מק"ט בדיוק.** תוסף הסנכרון **מפיל הזמנה
   שלמה** שמכילה פריט שלא קיים בקומקס — בשקט, בלי שגיאה
   (`site-comax-sku-must-match`). ההצלבה היא מול קובץ הפריטים ב-`content/`,
   ואם משהו חסר — קודם `items-export` טרי, ואז `comax-items`, ורק אז האתר.
   **ואסור "לנרמל כדי שיתאים"** — `3468333894005-41342` אינו
   `3468333894005`.
2. **הסימון "לא להציג" בוטל בקומקס** במסך נתוני אתר
   (`site-display-flag-must-be-cleared`). זה שלב שאין לו שום סימן חיצוני:
   מוצר יכול להיות מושלם בשני הצדדים ועדיין לא לדבר.
3. **יש תמונות.** מוצר בלי תמונות אינו מוצר — הסקיל רץ **לפני** הכתיבה לאתר,
   לא אחריה.

## מלכודות

1. **`_price` ו-`_regular_price` הם שני שדות.** כתיבת אחד בלבד מייצרת מוצר
   שנראה תקין בממשק הניהול ולא מתומחר בחזית.
2. **הסלאג של המונח אינו שמו.** `attribute_pa_color` מקבל
   `803-neon-blue-team-orange`, בזמן שהמונח עצמו נקרא
   `803-NEON BLUE-TEAM ORANGE`. כתיבת השם תיצור ווריאציה שלא תיבחר לעולם.
3. **`_wm_instock_terms_pa_color` / `_pa_size` נוצרים על ידי תוסף** שמסתיר
   צבעים ומידות שאזלו. **לא לכתוב אותם ידנית** — הם ייבנו מעצמם.
4. **צבע או מידה שלא קיימים כמונח — צריך להקים קודם** (`wp_manage_terms`).
   הקצאת מונח שלא קיים נכשלת בשקט, והמוצר נשאר בלי אותו צבע.
5. **`comax_id` שבווריאציות הוא שדה נטוש** — לא לעדכן אותו, לא להסתמך עליו
   (`site-sync-matches-on-sku-only`).
6. **קופסאות מיקס** — משפחת פריטים שבה כמה צבעים באתר חולקים ברקוד פיזי אחד
   (`mix-box-shared-barcode-pattern`). מוצר כזה אינו הקמה רגילה; לעצור ולשאול.

## מה עדיין לא אומת

- **יצירת מוצר או ווריאציה בפועל דרך ה-MCP לא הורצה.** כל המפה למעלה נקראה
  ממוצרים קיימים. בפרט לא אומת ש-`wp_create_post` עם `post_type:
  product_variation` + `parent` מייצר ווריאציה שוורדפרס באמת מכירה, ולא
  אומת שהוא מפעיל את `wc_delete_product_transients` — ייתכן שיידרש שמירה
  ידנית אחת במסך המוצר כדי לרענן.
- **סנכרון המלאי מקומקס לאתר** — לא מופה כאן בכלל.
- **מדריך המידות** (`size_guide` / `size_guide_link`, שדות ACF) — נראה בשדות
  ולא נבדק איך ממלאים אותו.
