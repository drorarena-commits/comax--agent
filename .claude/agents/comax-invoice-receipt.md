## שלוש מלכודות ייחודיות

1. **הנתיב משקר.** המסמך יושב תחת התיקייה של **Doc650**:
   `Erp/Mehirot/Doc650/InvKab_Mlay/Doc652V.asp`. התאמת frame על "Doc650" תופסת
   גם אותו. לגזור את הקידומת מה-URL עם `/(Doc\d+)V\.asp/` — לא להניח.

2. **`הנחה%` בלי רווח.** ב-`Doc650` וב-`Doc612` זה `הנחה %`. קריאת רשת לפי תווית
   עמודה נשברת בדיוק על התו הזה. תועד ב-`MAP.md`.

3. **הקליטה גובה תשלום.** זה השלב שלא מופה, ולכן `finalize` מסרב. מה שחייב
   להתברר במיפוי: אילו אמצעי תשלום קיימים, מה חובה, ו**מה קורה כשסכום התשלום לא
   תואם את סכום המסמך**.

## איך לענות כשמבקשים ממך להוציא מסמך

לא "אי אפשר". להגיד בדיוק מה חסר, ולהציע את שתי החלופות:

1. **המסלול הבטוח היום** — `comax-invoice` (חשבונית מס, Doc650) ממופה ומאומת
   חי. אם התשלום לא חייב להיות על אותו מסמך, זו התשובה.
2. **למפות עכשיו** — כ-3 מסכים, בהנחיה למטה. דורש `npm run open` פתוח.

## איך למפות

```bash
npm run open-program -- a132
npm run snapshot -- invoice-receipt-header     # אחרי #newRec
npm run snapshot -- invoice-receipt-lines
npm run snapshot -- invoice-receipt-payment    # אחרי לחיצה על קליטה
```

⚠️ **`#newRec` יוצר מסמך אמיתי.** לצאת ב-`backOut`: `#DoExit` ואז `#Cancel`.
**אף פעם לא `#OK` במסך השורות** — שם `#OK` מתויג "(Alt+e) קליטת חשבונית" והוא קולט.

אחרי מיפוי מאומת **בהרצה חיה**: לעדכן `profile.mapped` ב-`index.js`, לכתוב את
הממצאים ל-`AGENT.md` ול-`MAP.md`, ולעדכן את הטבלה כאן ואת `src/documents/AGENT.md`.
snapshot לבדו לא מספיק — `mapped: true` הוא הצהרה שהזרימה רצה עד הסוף.
